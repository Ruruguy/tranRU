# 中文來源與模式切換修復（2026-11-09）

選定講者語言時，Gemini 改走帶來源語言提示的語音辨識，再以暫定原文平行翻譯目標欄；不再忽略選定語言而一律自動辨識。暫定翻譯送出前合併間隔為 300ms，並非首字延遲保證。指定中文時將辨識文字轉台灣繁體；服務明確回傳其他語言碼時顯示提示，該段不送翻譯。僅含拉丁字母的錯誤辨識不再因設定為中文就直接複製到中文翻譯欄。

模式切換不再因 starting 狀態直接忽略點擊，而會取消舊的演講啟動。較晚取得的麥克風軌道會停止，過期的啟動請求不再建立背景連線或覆蓋新狀態。雙向溝通採用瀏覽器原生音訊取樣率，再由 PCMChunks 轉成服務所需 16kHz，保留已修復的四條連線與失敗清理。

## 自檢（僅自審）

1. 需求：處理指定中文卻出現其他語言，以及演講啟動卡住時雙向入口無反應；原版線上與本機同步。
2. 驗證：97 項測試及建置通過，包含來源語言傳遞、衝突語言提示、模式取消與遲到麥克風釋放。實際 Chrome 頁面雙向入口可切換；未啟動使用者麥克風或付費 API 測試。
3. 風險：暫定譯文增加文字 API 用量且可能修訂；來源語言提示不等於辨識正確率保證。背景聲音與重複內容的誤辨識仍需實測。
4. 一致性：前端、測試與此紀錄同步；西班牙語獨立副本未變更。原版後端重新啟動後，先前工作階段金鑰須重填。
5. 使用：兩端重新整理、設定自身金鑰，再授權收音；雙向對話需要 Gemini 金鑰，手動文字服務選項不控制語音連線。

後續值得以實際中英對談及中文授課驗證首字延遲，不能以模擬測試宣稱實際收音成功。
