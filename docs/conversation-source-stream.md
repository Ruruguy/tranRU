# 雙向溝通發言原文串流

各語言連線收到 input／interim 時，依偵測語言與目標語言配對，直接更新對應發言欄。暫定辨識修訂替換同一段內容；正式辨識接替暫定文字，同語言 output 不重複附加。其他語言 output 照常串流。turn、boundary 重設該連線的暫存狀態，保留歷史文字；停止保留目前字幕。繁中原文經台灣繁體轉換。

收尾自檢（僅自審）：

1. 需求：中文、英文發言者的欄位可在翻譯回傳前顯示原文。
2. 驗證：92 項回歸測試與建置通過，測試含英語 interim 修訂、中文 input 即時顯示及避免重複回顯。未使用真實金鑰收音。
3. 風險：依賴服務回傳辨識文字與語言碼，無法消除服務端延遲；暫定辨識可能修訂。
4. 一致性：沿用既有連線，不新增 API 或麥克風來源，輸出與匯出使用相同累積內容。
5. 使用：停止聆聽後重新整理，重新啟動雙向溝通。

可再優化：以中英文自然對談實測首字延遲，再判斷是否需要額外的獨立辨識服務。
