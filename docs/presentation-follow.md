# 演講模式各語言獨立跟隨最新字幕

2026-11-07：一般逐字稿採共用列高；英文與日文較長時，把共用捲軸移到底端會使同列較短的中文離開可見範圍。演講模式改用各語言獨立捲動區，持續跟隨各欄最新已收到的文字。三語配置維持「原文橫列＋下方三個譯文欄」。單語及雙語配置同樣使用獨立欄。

各欄最多繪製最近三段有文字的字幕，並顯示時間及等待／失敗狀態。過長句子顯示可容納的最新句尾；各服務仍可能有不同翻譯延遲。遲到的舊段譯文依原文順序排列，不覆蓋較新的已完成譯文。所有紀錄保留於原始資料；離開演講模式會重新繪製完整逐字稿，匯出與摘要資料不變。

## 收尾自檢（僅自審）

1. 需求：已把演講模式從共用捲動改成逐語言跟隨，保留原本三語排版。
2. 驗證：78 項自動化測試通過；瀏覽器以 500 段中英日模擬字幕及極長新增譯文檢查各欄 scroll gap 在 1px 內，四欄最新句尾皆位於各自可見範圍；實際應用的進出演講模式和完整逐字稿回復無 console error。這是排版與事件驗證，未重新測試付費語音 API。
3. 風險：演講模式以最新內容優先，新增字幕會把手動回捲拉回最新；需要回看時請退出演講模式。特長句子無法整段同時塞進畫面，但最新句尾保持可見。
4. 一致性：一般逐字稿、摘要、匯出資料保留；本機靜態路由、GitHub Pages 模組版本、樣式及說明同步更新。
5. 使用方式：仍點「演講模式」，不需要新增設定；退出後回看完整逐字稿。最終回覆會告知更新與驗證範圍。

還能怎麼優化：目前無必須追加的功能；先以實際演講觀察字體大小與上方原文區高度是否合適。
