# 雙向溝通辨識引擎

演講與雙向溝通提供相同六種辨識引擎。雙向溝通保持二／三／四語欄位，四語一般與全螢幕皆為 2×2；各欄可選繁中、英文、日文、孟加拉語、西班牙語、德文、法文。

| 引擎 | 需要設定 | 辨識語言 |
| --- | --- | --- |
| Gemini 即時翻譯 | Gemini API 金鑰 | 自動偵測並即時口譯 |
| OpenAI 智慧停頓切段 | OpenAI 金鑰；所選文字翻譯服務須可用 | 自動或指定；停頓／短句切段後顯示 |
| Azure Speech | Azure Speech 金鑰與區域＋Gemini／OpenAI 文字翻譯金鑰 | 須指定 |
| Gemini 專業精準 | Gemini 金鑰＋可用文字翻譯設定 | 自動或指定；附醫療詞彙提示 |
| 原生語音 | 瀏覽器支援原生辨識＋文字翻譯金鑰 | 須指定 |
| 免金鑰 | 瀏覽器支援原生辨識及免費文字翻譯服務 | 須指定 |

「辨識語言」指定收音語言；各欄語言指定畫面顯示的語言，兩者用途不同。Azure／原生模式無法像 Gemini 即時口譯那樣自動輪流辨識多語。需要自由切換多語時選 Gemini 即時翻譯。

精準／原生模式先顯示暫定原文，文字翻譯可隨暫定結果更新，確定語句後校正；這會增加文字翻譯用量。停止會取消尚未完成的請求，保留已收到字幕；未完成的尾句可能缺字。清空會同步取消舊文字翻譯，避免清空後舊字幕重新出現。

## 驗證

以替身驗證引擎條件、辨識到四語字幕、正確路由翻譯、WAV 編碼、安靜時不結束、麥克風授權競態、停止與清空、舊暫定譯文不覆蓋定稿，以及開始按鈕確實選用指定引擎。未使用真實 Gemini、OpenAI 或 Azure 金鑰做真人收音驗收；免費服務與原生辨識仍受瀏覽器、地區和服務可用性限制。
