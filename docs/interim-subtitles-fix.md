# 本機演講字幕延遲修正

原因：Gemini 自動多語及精準辨識模式原先只在 final 事件後送文字翻譯，連續發言的 interim 辨識結果只有原文，譯文欄持續等待。

修正：暫定原文約 700ms 後對各選定語言平行送出文字串流翻譯；每個辨識段最多一組暫定請求執行中，完成後才取最新原文再更新。正式辨識、停止及連線中斷會取消暫定請求，忽略晚到結果。暫定譯文只用於顯示，正式翻譯仍負責紀錄、摘要與匯出。畫面會區分正在翻譯與沒有該語言歷史譯文。

## 自檢（僅自審）

1. 問題：移除必須等整句結束才出現譯文的限制；未承諾無網路延遲。
2. 驗證：91 項測試及靜態建置通過；新增測試證明 interim 譯文先出現、取消後晚到譯文不覆寫。未使用使用者金鑰進行真實收音。
3. 風險：增加文字 API 用量；暫定譯文隨辨識內容可能修訂，請以正式紀錄核對。
4. 一致性：頁面提示同步說明暫定譯文及費用；本機已改，未發布線上。
5. 操作：先停止聆聽，再重新整理本機網站並重新開始。

後續優化：以實際長句授課音訊量測辨識、文字翻譯各階段延遲，值得在下一次現場測試進行。
