# 原版雙向溝通啟動修復（2026-11-09）

- 瀏覽器與本機的翻譯連線上限由三條改為四條，第五條拒絕；連線關閉後可釋放名額。
- 原版即時對話語言選單與目前模型程式支援保持一致：繁中、英文、日文、孟加拉語。第四欄預設孟加拉語。西班牙語仍在獨立版。
- 麥克風啟動前驗證重複與不支援的目標語言，啟動中拒絕重複點擊。
- 點擊開始時先建立並喚醒 AudioContext，再等待 API 連線，避免長時間網路等待後才嘗試啟動音訊。
- 啟動超過 30 秒時清理並提示檢查權限、網路與額度；停止及失敗會恢復控制項，字幕保留。
- 四語一般及全螢幕維持等大 2×2；各格獨立捲動。

## 自檢（僅自審）

1. 需求：修復原版雙向溝通無法啟動、卡住及四語不可用的程式原因。
2. 驗證：92 項測試及建置通過，包含四條連線容量、取消後釋放、麥克風拒絕與連線失敗後重啟、發言原文即時更新與停止後保留。尚未使用真實 API 或音訊。
3. 風險：四條連線各自計費，帳戶額度、權限及網路仍可能使啟動失敗；30 秒逾時後需要重按開始。
4. 一致性：原版語言選單、容量測試、前後端限制同步更新；未改西班牙語副本。另提交前一輪的原版背景啟動工具修正。
5. 使用：線上部署完成後先停止，再強制重新整理；本機後端要重啟以載入四連線限制，重啟後工作階段金鑰需重填。

後續值得用真實中英日孟加拉語對談驗證首字延遲，不以模擬測試宣稱端到端收音成功。
