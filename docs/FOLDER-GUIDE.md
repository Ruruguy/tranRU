# 專案資料夾導覽

本專案僅維護一條路線：11/08 最後版本 ae70034，加上西班牙語與四語 2×2 的必要支援。

- 根目錄：唯一主專案；雙擊「啟動翻譯.command」，使用 http://127.0.0.1:8787/。
- public/：唯一線上及本機網頁程式。
- server.mjs：本機服務。
- 根目錄 *.test.mjs：本專案測試，npm test 執行。
- scripts/：靜態建置；npm run build 產生 dist/。
- dist/：自動產生的發布檔，不手動編輯或提交。
- docs/：說明與歷史檢視紀錄。
- artifacts/：本機測試、日誌或清理收據，Git 忽略，不發布。
- .git/：保留完整歷史與整合前備份標籤，不是另一份執行版本。
- .agents/、.openai/ 與 :memory:.ses：本機工具資料，未當作網站副本清除。

「11-08」與「含西班牙語」為整合前副本，整合後移至垃圾桶，不再使用 8786、8788。「翻譯團隊」及部署還原暫存亦已移至垃圾桶；依使用者要求保留獨立舊專案「雙語即時字幕-邱」，不作為 tranRU 維護路線。
