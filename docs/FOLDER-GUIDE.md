# 資料夾導覽

- `public/`：tranRU 網頁、字幕排版與瀏覽器 API 客戶端。
- `server.mjs`：本機服務；`npm start` 啟動。
- 根目錄 `*.test.mjs`：本專案測試；`npm test` 執行，避免掃入其他子專案。
- `scripts/`：靜態建置工具。
- `dist/`：自動產生的 GitHub Pages 發布檔，不手動編輯、不提交。
- `docs/`：操作、設計及檢視紀錄。
- `docs/archive/`：早期需求、專案和測試筆記，僅供歷史參考；本次由根目錄移入，內容未改寫。
- `翻譯團隊/`：另一套含 Electron 與自身測試的獨立程式，保留原位置。
- `雙語即時字幕-邱/`：另一套含 Windows 啟動工具的字幕程式，保留原位置。
- `.agents/`、`.openai/`、`:memory:.ses`：本機工具資料，未整理搬動，勿加入網站發布。

金鑰、錄音、逐字稿與其他子專案未加入本次提交或發布範圍。
