# 懸浮字幕與 Mac 透明字幕（2026-11-17）

網站保留 Document Picture-in-Picture／一般彈出窗，新增三種風格、自訂字色底色、18–64 px 字級、一至五行、語言選擇及原文顯示開關。預設只顯示主要譯文，保留最新句尾；雙向溝通也會同步。

真正系統透明由桌面工具實作，網頁視窗不冒充可透出 PPT 的系統透明窗。Mac 工具使用非不透明、無邊框 NSPanel，清除背景，使用透明文字容器與文字描邊；不使用截圖假背景。預設滑鼠穿透、可跨桌面並作全螢幕輔助視窗；外接投影及 PPT 全螢幕仍需依使用者實際場景驗收。

工具為同一維護路線下的顯示配件，不含另一套收音或翻譯引擎。網站繼續收音與翻譯，透過本機連線傳送文字。

## 本機連線

- 僅監聽 127.0.0.1:8799。
- 允許來源限官方 GitHub Pages 網域與本機 8787；驗證 Host，拒絕其他 Origin。
- 每次啟動以系統亂數產生 128-bit 連線碼。必須先驗證工具身分與連線碼，才傳送字幕。
- 連線碼只留頁面與工具記憶體，不放 localStorage、網址、日誌或版本庫。
- 僅傳顯示用文字、語言名稱與必要樣式，移除金鑰、錄音及其他欄位；限制本文與文字大小。
- 暫時斷線會退避重試並採用最新字幕，避免堆積舊畫面；手動停止會取消重試並通知工具隱藏。
- 線上網站首次連接回送位址時，瀏覽器可能要求本機網路權限；不繞過權限、不停用安全檢查。

## 驗證與限制

Node 測試涵蓋配色驗證與上限、字幕語言／原文選擇、HTML 逸出、重繪與句尾追蹤、本機資料最小化、身分驗證先於傳字幕、連線錯誤／重試／取消；macOS 協定自測與實際本機 HTTP 測試涵蓋連線碼、來源、Host、CORS 與本文上限。已開啟 Mac 工具並透過網站成功配對，工具確認收到字幕。

未使用付費 API 真人收音驗證此次顯示功能，亦未完成使用者 PPT 全螢幕與投影場景驗收。套件為本機編譯、ad-hoc 簽章，尚未 Apple 公證；Apple Silicon 已啟動，Intel 為交叉編譯，未於 Intel 實機執行。
