# Gemini 修改版檢視與修正

保留 Gemini 的兩種模式及語言數設定、三欄與 2×2 版面。此次檢視修正：

- 一般演講與全螢幕共同使用固定字幕欄，避免渲染已隱藏的逐句卡片。
- 對話各目標語言獨立累積字幕與處理句尾，不由第一條連線清除其他連線的未完成結果。
- 發言欄位提示依已選語言對應，不再假定中英日固定位置；提示只代表語言，不辨識個人身分。
- 停止聆聽保留字幕，清除後重新掛回字幕容器；即時字幕可匯出。
- 第三、第四欄文字輸入依來源語言分別翻譯至其他已選語言。
- 開始自動多語聆聽需 Gemini 金鑰，手動文字翻譯服務獨立設定；連線期間鎖定語言設定及對調，避免標籤與字幕不一致。
- 中文正規化依目標語言判定；字幕錯誤提示復原後移除。
- 勾選框與文字同行；校對「手動文字翻譯完成後朗讀」範圍。
- npm test 僅執行根目錄本專案測試。早期筆記搬入 docs/archive，獨立子專案原位保留，見 FOLDER-GUIDE.md。

## 收尾自檢（僅自審）

1. 原需求：以 Gemini 修改版為基礎除錯、校對並整理資料夾，保留設計方向。
2. 驗證：完整回歸測試、靜態建置、瀏覽器模式切換與四語 2×2 幾何確認；額外測試四語重排及延後到達的輸出，停止後仍保留字幕。未使用真實 API 或長時間現場收音。
3. 風險：多條語音連線分別計費，無法保證不同服務結果逐句同步；完整累積文字的長時間效能仍需量測。
4. 一致性：操作文字、測試範圍與資料夾導覽同步；本次在本機完成，未自動發布 Gemini 大幅修改後的整份版本。
5. 使用方：本機重新整理載入；提供檢視紀錄與驗證限制，線上維持先前已發布版本。

## 還能怎麼優化
