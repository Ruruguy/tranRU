# tranRU Mac 透明字幕 · 製作者：大佛A-Ru

適用 macOS 14 以上，包含 Apple Silicon 與 Intel。此工具只顯示字幕，不負責收音或翻譯。

1. 解壓縮並開啟「tranRU 透明字幕.app」，保持工具執行。
2. 複製工具中的連線碼。
3. 網站按「字幕樣式」，把連線碼貼入「Mac 透明字幕」區，按連接。
4. 若瀏覽器詢問是否允許連接本機網路／這台裝置，確認正在使用自己的 tranRU 工具後允許。請使用目前版本 Chrome 或 Edge；拒絕權限時網站會顯示連線失敗。
5. 開始網站翻譯，回到 PPT 播放。字幕為真正透明背景，預設鎖定且滑鼠穿透。
6. 在網站調整字色、字級、顯示語言、行數；Mac 工具可調字幕位置、寬度與額外字體縮放。解除鎖定可拖曳字幕，完成後重新鎖定。
7. 網站按停止同步會隱藏字幕；Mac 工具選單可結束工具。僅停止收音時保留最後字幕。

連線碼不是 Gemini／OpenAI API 金鑰。工具每次啟動產生新的隨機連線碼，只保存在記憶體。請勿將連線碼公開。網站不保存連線碼，重新整理需重新貼上。

僅監聽 127.0.0.1:8799，允許 https://ruruguy.github.io、http://127.0.0.1:8787 與 http://localhost:8787。來源檢查與隨機連線碼驗證皆需通過；不接收 API 金鑰、錄音，不將字幕或連線碼寫入日誌／檔案。

本工具為本機編譯並以 ad-hoc 簽章處理，尚未經 Apple 公證。請只使用此專案提供並核對雜湊的版本；不要關閉整體系統安全防護。全螢幕、不同桌面或投影螢幕的行為仍需依實際 PPT 設定測試；部分投影／錄影方式只擷取簡報視窗，不一定包含懸浮層。

開發建置：執行 desktop/mac/build.sh。產物位於 Git 忽略的 artifacts/mac-overlay-v1.1.0，不包含任何 API 金鑰。


1.1.0 字體更新：預設 48 px、每語言兩行，使用實心黑體與清楚描邊，移除模糊陰影。Mac 工具改為顯示完整的最後幾行，並提供可選的文字護底；護底會依字色選擇深／淺底。舊版工具請先結束，再開啟新版並重新連接。多語言或小螢幕可減少行數，避免佔滿簡報。實際投影距離仍需現場確認。
