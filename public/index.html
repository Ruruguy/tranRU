文字手動翻譯／連線測試

Gemini 模式會將音訊連續傳送至 Google；OpenAI 模式會傳送至 OpenAI，兩者依 API 額度計費。 Gemini 為預覽服務，自動偵測原語言，僅顯示字幕、不播放譯音（服務仍可能計算音訊輸出費用）。 自動備用啟用後，Gemini 中斷將改由 OpenAI 處理後續收音；切換期間的未完成字幕可能缺漏。 線上演講請選取分頁並勾選「分享分頁音訊」。免金鑰模式使用瀏覽器語音辨識，翻譯可能將辨識文字傳送至 Google；僅支援麥克風與指定演講語言。
